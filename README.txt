X翻译 (XTranslate) v0.7.3
==========================

屏幕翻译工具，支持截图 OCR、截图翻译、划词翻译、文本替换、朗读剪贴板、
插件扩展等能力，驻留系统托盘，热键全局触发。

-----------------------------------------------------------------------------
一、安装与运行
-----------------------------------------------------------------------------

  1. 解压 dist/XTranslate/ 到任意目录（推荐 C:\Program Files\XTranslate\）。
  2. 双击 XTranslate.exe 启动，启动后驻留系统托盘。
  3. 首次启动会在 %APPDATA%\XTranslate\ 写入 config.json（默认配置）。

-----------------------------------------------------------------------------
二、内置快捷键（可在 设置 → 快捷键 修改）
-----------------------------------------------------------------------------

  Alt+D   截图翻译      （拖选屏幕区域 → OCR → 译文覆盖层）
  Alt+S   截图 OCR      （拖选屏幕区域 → OCR → 结果对话框）
  Alt+X   划词翻译      （选中文本 → 弹出译文卡片）
  Alt+T   文本替换      （选中文本 → 翻译 → 就地替换原文）
  Alt+M   显示/隐藏主窗
  Alt+R   朗读剪贴板    （无可用语音引擎时禁用）

-----------------------------------------------------------------------------
三、设置项
-----------------------------------------------------------------------------

  · 常规：界面语言、主题（浅色/深色/跟随系统）、开机启动、划词翻译开关、
          历史记录上限、通知开关（总开关 + 截图 OCR / 截图翻译 / 划词 / 替换 /
          热键冲突提示）。v0.7.2：热键冲突默认不弹气泡仅写日志；
          "已最小化到托盘"仅首次提示一次。
  · 快捷键：六个动作各自单独录制组合键，应用后立即生效。
  · 翻译服务：优先级排序、密钥配置、单服务测试。
  · OCR：本地 Paddle OCR（精度高，含坐标）/ 系统 OCR（启动快，不依赖模型）。
  · 朗读（TTS）：启用开关、朗读引擎（云端 Edge 神经嗓音，默认/推荐，
          全语种无需本机语音包；或系统嗓音）、按语言选择偏好嗓音、
          测试朗读。云端失败自动回退系统嗓音，系统无专用嗓音再回退
          默认嗓音。注：云端语音为非官方免费接口，需联网，仅供个人学习。
  · 代理：不使用 / 系统 / 手动 HTTP 代理（含可选鉴权）+ 测试。
  · 插件：进程外翻译插件管理，支持 plugin.exe | plugin.py | plugin.bat 三种入口。
  · 关于：版本号与开源组件声明。

  主窗入口（v0.7.1 去菜单栏）：工具条右侧"历史"图标钮展开/收起右侧
  历史面板，"设置"齿轮图标钮打开设置；托盘菜单同样可达设置，并新增
  "目标语言"子菜单快捷切换翻译目标语言（与主窗下拉即时同步）。

-----------------------------------------------------------------------------
四、翻译服务
-----------------------------------------------------------------------------

  内置 10 个翻译 provider：
    Google（免费）、Bing（免费）、DeepL（需 Auth Key）、百度翻译（需 AppId+密钥）、
    有道智云（需应用 ID+密钥）、腾讯云 TMT（需 SecretId+SecretKey）、
    OpenAI 兼容（需 baseUrl+API Key+模型）、DeepLX（需实例地址）、Lingva（需实例地址）、
    Mock（兜底，离线返回 [MOCK] <text>）。

  在 设置 → 翻译服务 中按优先级排序，勾选启用的服务参与自动调度，
  未配置密钥的服务显示为灰色不参与调度；任意服务失败自动降级到下一个。

-----------------------------------------------------------------------------
五、OCR 引擎
-----------------------------------------------------------------------------

  · 本地 Paddle OCR：内置 PP-OCRv6 small 检测 + 识别模型，部署在 models/
    子目录，开箱即用，支持行级坐标输出（用于截图翻译覆盖层）。
  · 系统 OCR：调用 Windows.Media.Ocr，不依赖 ONNX 模型，启动更快；
    需 Windows 10+ 与已安装 OCR 语言包（设置 → 时间和语言 → 语言 → 添加语言 →
    勾选"光学字符识别"）。系统 OCR 不暴露像素坐标，仅用于截图 OCR。

  在 设置 → OCR 中切换，立即生效；截图 OCR / 截图翻译 / 区域 OCR 共用此设置。

-----------------------------------------------------------------------------
六、翻译插件
-----------------------------------------------------------------------------

  插件目录：%APPDATA%\XTranslate\plugins\
  环境变量 XTRANSLATE_PLUGINS_DIR 可完全取代默认路径。

  插件目录布局：每个子目录视为一个插件，主入口文件名固定为
  plugin.exe / plugin.py / plugin.bat（优先级 exe > py > bat）。
  子目录名即插件 name，必须与 describe 返回的 name 字段一致。

  通信协议（v1，JSON over stdio）：
    请求 {"op":"describe"}
      -> {"name":"<subdir>","version":"<x.y.z>"}
    请求 {"op":"translate","text":"...","from":"...","to":"..."}
      -> {"text":"...","provider":"plugin:<name>"}
       或 {"error":"..."}
    其他 op -> {"error":"unknown op: <op>"}

  示例插件见 examples\plugin-echo\，运行：
    cd examples\plugin-echo
    python plugin.py
    {"op":"describe"}
    {"op":"translate","text":"hello","from":"en","to":"zh-CN"}

  探测成功的插件会出现在 设置 → 插件 列表中。插件以 mock 同样的方式
  参与 provider 调度（name="plugin:<插件名>"）；当前不参与自动降级链，
  需在主窗服务商下拉框手动选中或通过 --provider plugin:<name> 触发。

-----------------------------------------------------------------------------
七、开机启动
-----------------------------------------------------------------------------

  设置 → 常规 → 启用"开机启动（驻留托盘）"，自动写入注册表
  HKCU\Software\Microsoft\Windows\CurrentVersion\Run\XTranslate
  命令行 `"<exe>" --minimized`，登录后无窗口驻留托盘。
  取消勾选则删除注册表项。启动时若发现配置与注册表不一致，以配置为准自动校准。

-----------------------------------------------------------------------------
八、自助自测（selftest）
-----------------------------------------------------------------------------

  XTranslate.exe --selftest <mode>
  支持模式：env | ocr | translate | capture | overlay | hotkey | tts |
            selection | config | db | providers | theme |
            replace | systemocr | plugin
  每个模式输出一行 JSON 到 stdout，exit code 0 = pass。
  批量回归：powershell -File tools\phase5_run_selftests.ps1

-----------------------------------------------------------------------------
九、文件结构
-----------------------------------------------------------------------------

  XTranslate.exe                 主程序
  models\paddleocr\pp-ocrv6-small\   Paddle OCR 模型
  examples\plugin-echo\              echo 插件示例（开发参考）
  plugins\                           用户插件目录（首次启动时创建）
  LICENSE                            MIT 开源许可证
  THIRD-PARTY-NOTICES.txt            第三方组件版权声明
  README.txt                         本文件

  用户数据：
    %APPDATA%\XTranslate\config.json   配置
    %APPDATA%\XTranslate\history.db    历史记录
    %APPDATA%\XTranslate\plugins\      用户插件

  卸载行为：
    卸载时保留个人配置与历史记录；如需彻底清除，请手动删除
    %APPDATA%\XTranslate 目录。
